# Changelog

All notable changes to openHLSW are documented in this file.
The entries are generated by semantic-release from the Conventional Commits
(https://www.conventionalcommits.org/); versions follow Semantic Versioning.

## [v0.2.0] - 2026-10-21

### Added
- **Toolbar with icons like HLSW**: Connect | Rcon section, Server list, Rules (pressed while
  shown) | Delete | Refresh, refresh interval, Update | Server List Properties, Server
  Properties | About. Refresh switches the automatic refresh on and off, Update refreshes all
  servers once while it is off. The icons are drawn for openHLSW (`assets/icon-sources/toolbar/`).
- **"?" menu and About openHLSW window** like HLSW's (banner, version, license, homepage).
- **ClearType-like text** on Windows, Linux and macOS: glyphs use the red, green and blue
  stripes of every screen pixel, which makes small text much sharper. Settings → Misc →
  Text smoothing: Automatic (on for normal screens, off from 150 % / Retina), ClearType
  (RGB / BGR) or Grayscale. Needs OpenGL 3.3; older drivers keep gray text. Two of egui's
  crates are included in a modified form for this (`vendor/`, see `vendor/README.md`).
- **Fonts**: every font installed on the computer can be chosen, each shown in its own look in
  the list; **text size** 12, 13, 14, 15 or 16 px.
- **Type to find in dropdowns**: typing in an open list jumps to the matching entry ("de" →
  Deutsch), Enter picks it – in the settings and in the main window.
- **Player name** in the toolbar like HLSW: a dropdown of the names used before and a delete
  button.
- **Multi Kick, Multi Ban ID, Multi Ban ID Kick, Multi Ban IP …** in the players' right-click
  menu when several players are marked.
- Windows installer: pictures in the style of the About banner on all pages of the setup wizard.
- **All games of the game list are supported**, plus the games of GameQ's list (about 180
  games). New queries: GameSpy 1, Unreal 2, Quake 1 / 2 / 3, Medal of Honor, Doom 3,
  All-Seeing Eye, Frostbite (Battlefield Bad Company 2, 3, 4, Hardline), TeamSpeak 2 / 3,
  Ventrilo, Mumble, Tribes 2, Savage, Frontlines, SA-MP, Teeworlds, OpenTTD, Minecraft
  (Java and Bedrock), FiveM / RedM, Counter-Strike 2D, Tibia, StarMade, Lost Heaven and Mafia 2
  Multiplayer, Terraria (TShock), Eco and Stationeers (HTTP). Valve games with their own query
  port (ARK, Squad, Rust, Valheim, …) get it filled in. The usual port of the chosen game is used
  when the address has none. Shockvoice has no documented query: only whether the server can be
  reached is shown.
- **Auto detect finds GameSpy 1 and GameSpy 2 servers** as well as Valve servers.
- Game icons are shown at 16x16 screen pixels (the icons' own 16 px pictures, 32 px ones on
  high-DPI screens), sharp and never cut off; in a row that is too low they are scaled down
  as a whole.
- Servers that need a password to join show HLSW's gold key next to the game icon in the
  server list; every row keeps room for the key, so the names stay in line.
- Connect for the new games: the game from My Games with the server address (Quake / Doom 3
  `+connect`, Unreal `ip:port`, Battlefield 1942 `+joinServer`, …) or the client's link
  (TeamSpeak, Ventrilo, Mumble, SA-MP, FiveM / RedM).

### Changed
- **Look like HLSW 1.4**: flat toolbar buttons, white list frames, HLSW's header and line
  colours, compact spacing; dialogs (Settings, Properties, About, …) are real windows of the
  operating system with its title bar.
- **Settings → Misc** laid out like HLSW: Server list (incl. Connect on double click), Language,
  Skin, Font with text size and text smoothing, Global ID Database. Dropdown lists open
  downwards and scroll when they are long.
- Default look: the **system font** (Segoe UI on Windows) at **13 px**; existing settings are
  switched once.
- **openHLSW brings no fonts of its own any more**: all text uses the fonts of the system
  (the console its monospace font). A chosen font that is missing falls back to the system font.
- The "Auto refresh every" check box is gone: the toolbar's Refresh button does that, the
  interval is next to it.
- The rules list marks one rule at a time, like HLSW.
- The player name field is empty until you type a name (the hint is in the tooltip).
- **Builds** run on the newest long-term images: Ubuntu 26.04 (x64 and arm64), Windows Server
  2025, macOS 26; the Flatpak uses the Freedesktop 26.08 runtime; the FreeBSD package is
  built on FreeBSD 15 (it needs FreeBSD 15 or newer). The Linux binaries are still built
  with an old glibc, so they keep running on older distributions.
- The build uses the current versions of its GitHub actions (Node.js 24).
- Server info panel: the game's icon is shown before the game name.
- Server info panel: the server name is bold, two sizes larger, in the normal text colour (no
  longer a blue, underlined link), the ping graph has a 1 px black frame, the text below the
  graph keeps 2 px more distance from the panel's left border, and the panel lines up with the
  server list and the Rcon box.

### Fixed
- **Adding servers**: a new server was hidden while the server list filter was on (it had
  not answered yet), so Add seemed to do nothing. New servers now stay visible until they
  answer, the list scrolls to the added server, problems (invalid address) open a message
  window, and the address field can no longer cover the Add button. The same server can be
  in several server lists.
- **Players not updated** (frozen time and frags) on servers that allow only about one query
  per second (many HLDS, or after dropped queries): the server info used up all queries.
  Info, players and rules now take turns, so all three stay current.
- The rules list's header covered the white frame line at the top left; no list paints over
  its frame any more. The rule numbers have one pixel more room to the frame.
- Blurry text at some sizes: font sizes are snapped to whole screen pixels.
- **RCON password**: typing it no longer logs in to the server on every key (servers ban
  addresses after a few failed RCON logins). The server is asked when Test (or Enter) is
  pressed or a command is sent; after "Bad password" openHLSW stops logging in by itself
  until Test is pressed again.
- Hidden passwords show clean, round dots with a little room between them.
- Questions and messages (Delete server, Delete server list, Change level, Add errors …) look
  like HLSW's / Windows' message boxes: icon and text on a white area, OK and Cancel on the
  right of a gray band; Enter = OK. Small dialogs fit their content instead of leaving empty
  space below it.

### Removed
- The bundled fonts (Inconsolata, Liberation Sans, Wine's Tahoma) and egui's built-in fonts.
- Deer Hunter 2005 from the game list (its servers still work as `ip:gameport:queryport`
  with Auto detect).
- The message about a missing GameSpy query port: without one, the game port is asked.

### Security
- Tests, examples and the test server use documentation IP addresses instead of real ones.

## [v0.1.4] - 2026-10-20

### Added
- **Game list like HLSW** next to "IP/Port": **Auto detect** (Source, Half-Life 1 and CS2
  are recognised by themselves), the **not detectable games** (Armed Assault, Crysis,
  GRAW 2, Sniper Elite, …) and **all games** of HLSW with their icons. Games whose query
  protocol openHLSW does not speak yet are greyed out; for GameSpy 2 games with a known
  query port (e.g. ArmA: 2303) `IP:port` is enough.
- **Battlefield 2 / 2142** (GameSpy 3 queries with split answers and challenge):
  - mods are told apart like in HLSW, e.g. "BF2 - Special Forces Expansion (gpm_coop)",
    with the green "2" for Special Forces and a brown one for Battlefield 2;
  - players with score, deaths, skill, ping, team name and bot flag; bots are counted in
    brackets ("0 (4) / 32");
  - operating system, dedicated, PunkBuster, VOIP and friendly fire from the `bf2_*` rules;
  - Connect joins the server directly (`+modPath mods/<mod> +joinServer <ip> +port <port>`,
    password and `+playerName`).
  - Battlefield 2142, Vietnam, ArmA, ARMA 2, Crysis and Crysis Wars get their own icons
    and names.
- **Marking rows** in the players and rules lists: click, Ctrl+click, Shift+click, Ctrl+A,
  Ctrl+C. The right-click menu acts on all marked rows (copy one line per row, kick, ban,
  open Steam profiles, Global ID Database type, "Marked Rows" copy).
- **Arrow keys** move through the server list, the players and the rules (with Shift the
  marking grows in the players and rules lists).
- **Every RCON command** a button sends (`listid`, `listip`, `maps *`, `listmaps`, kick,
  ban, `say`, `logaddress_add`, `log on`, …) is shown in the console together with the
  server's answer.

### Changed
- **Ping graph**: fixed scale – 10 ms stays near the bottom, 100 ms reaches the middle,
  200 ms the top (only servers that are slow all the time widen it). Every bar runs from
  green at the foot through yellow (100 ms) to red (200 ms).
- **Offline servers** always go to the end of the server list (sorted among themselves the
  same way) and move back up as soon as they answer again.
- Games without RCON (GameSpy) show the Rcon section greyed out instead of asking for a
  password; the RCON password in Server Properties and "Rcon Status Command" are greyed out
  as well.
- Server list filter: "Hide servers that do not answer" is now off by default.

### Fixed
- Windows: the Start menu and the taskbar showed a blank white icon. The installer's icon
  now has the `.ico` name Windows needs for Start menu shortcuts, and the .exe embeds the
  small icon sizes as bitmaps instead of PNG.
- Ban list: IPs of Half-Life 1 servers (`203.  0.113. 52`) were cut off; Unban now removes
  the right IP.
- Battlefield 2 servers (`ip:port:queryport`) did not answer the old GameSpy 2 request.
- Servers disappeared from the list once they were offline while the filter was on.
- The current and the average ping in the ping graph were drawn on top of each other.
- Chat: your own messages ("Message to all players") did not show up in the chat window
  when the server log did not reach openHLSW; Half-Life 1's `Server say "…"` log lines are
  recognised.

## [v0.1.3] - 2026-10-20

### Added
- The user interface is available in 18 languages: English, German, French, Spanish
  (Argentina), Portuguese (Portugal), Dutch, Danish, Swedish, Norwegian, Finnish, Polish,
  Czech, Slovak, Hungarian, Turkish, Russian and Chinese (Simplified and Traditional).
  Settings → Misc → Language; by default openHLSW follows the system language.
- **Server list filter**: "Filter" check box and "Edit filter..." in the toolbar. Hides
  servers by timeout, ping, password, game, map, country, AddOns, players, slots, free
  slots and time / frag / round limits; the top right shows "X of Y servers".
- **Find**: Server → Find → Server Name (Ctrl+F), Player..., Rule... across all servers of
  the list, Find Next (F3). The Rcon console has its own find ("/" switch,
  Ctrl+Shift+F, F3) that highlights the hits.
- **Global Player ID Database** (File menu, Ctrl+W): Steam IDs with names, type (Normal,
  Friend, Lamer, Blue, Brown – colours the player name), comment and banned flag. Names
  are added automatically from `status` (Settings → Misc). Import / export `banned.cfg`,
  player columns "Global ID Database Names / Comment" and a right-click submenu on players.
- **Ban List**: Write (`writeid` / `writeip`), Reload, filter field and transfer of bans to
  and from the Global ID Database.
- **Admin Notification** (Rcon Config): chat messages starting with `@` play the
  notification sound and are shown in the status bar.
- **Connect**: player name (View → Player Name, passed as `+name`), start parameters per
  game (Settings → My Games, right-click presets such as `-novid` or
  `+rcon_password <RCONPASSWORD>`) and per server (Properties → Additional parameters).
  Asks before connecting to a password protected server without a password and waits for a
  free slot on full servers ("Connecting..." window, connects automatically).
- Settings → Connecting: new option **Quit openHLSW** after connecting.
- Server list menu: **Import Steam Favorites** and **Search LAN** (ports 27015-27030).
- File → Advanced: clear the location and provider cache, reset all ping graphs.
- Confirmations before deleting a server and before changing the level.

### Changed
- Selectable user interface font under Settings → Misc → Font: **Arial** (default),
  **Tahoma** (HLSW's font) or **Inconsolata**. Windows uses its own Arial and Tahoma;
  Linux and macOS use them when installed and otherwise bundled replacements (Liberation
  Sans for Arial, Wine's Tahoma). Inconsolata is bundled and also used for the console.
  The font licenses are shown under ? → License.
- Buttons and labels grow with their (translated) text instead of cutting it off.
- The default text size is now **Large (115 %)**; existing settings are kept.
- Release packages: Linux **x86_64 / aarch64** (`.tar.gz`, `.deb`, `.rpm`, new **Flatpak**)
  and new **riscv64** (`.tar.gz`, `.deb`, `.rpm`); Windows x64 / x86 / arm64 (`.msi`,
  `-portable.zip`); macOS now as a **universal** app for Apple silicon and Intel (`.dmg`,
  `.zip`); new **FreeBSD x86_64** (`.tar.gz`). The 32-bit Linux build is no longer
  provided.

- Sharper, evenly spaced text: fonts use light hinting (horizontal strokes and baseline on

## [v0.1.0] - 2026-10-18

First release: a native HLSW 1.4 remake for Windows, Linux and macOS (Apple silicon),
written in Rust
(egui/eframe). One binary, no runtime.

### Look and feel
- Layout like HLSW 1.4: toolbar and server list on top, server info (bottom left), players
  (right), rules (bottom right), Rcon section with tabs at the bottom, status bar with
  online count and send/receive traffic.
- Skins White (default) and Black; starts maximized; title "openHLSW - v<version>" (e.g. "openHLSW - v0.1.0");
  program and window icon (orange crosshair with a server).
- Text size (Settings → Misc): Normal, Large, Extra large.
- Crisp text: font hinting with grid fitting, no sub-pixel glyph blur; Tahoma with fallback
  fonts, so player and server names in every script (symbols, CJK, Cyrillic, emoji …)
  display correctly (UTF-8, with Latin-1 fallback for old servers).
- Country flags and game icons from embedded image atlases that may have any resolution
  (RGB or RGBA flags, icons in any .ico size); game icons are stored at 32 px and cropped to
  their visible part, so they stay sharp at larger text sizes.
- Copy / paste / cut in every text field (Ctrl+C/V/X/A and a right-click menu with Cut,
  Copy, Paste, Select All).
- Every pane has a small margin, panel sizes are remembered.

### Menus and shortcuts
- File: Connect Log, open the AppData folder, Minimize (also "no traffic"), Exit.
- Server list: New, Open, Delete, Properties (rename), Import, Export, Multi Server Insert.
- Server: Connect, Copy, Delete, Move/Copy to server list, Find, Edit comment, Change ID,
  Reset Average Ping, Properties, Trace Route, Rcon Status Command.
- Settings: Settings dialog, Sort Server List (IP/Port, Game + Name, Game + IP/Port, …).
- View: Rcon Section, Server List, Rules, Password, Filter, Comment, Toolbar, Status Bar,
  Ping Graph, Skin.
- Shortcuts like HLSW: F5 (refresh all), F6 (refresh selected), Ctrl+G (connect),
  Ctrl+D / Del (delete), Ctrl+F (find), Ctrl+P (properties), Ctrl+T (trace route),
  Ctrl+I (multi insert), Ctrl+O (list properties), Ctrl+R / Ctrl+L / Ctrl+U (show Rcon
  section / server list / rules), Ctrl+M (minimize), + / - (change ID).

### Supported servers
- **Source** (SRCDS: CS:S, CS:GO, CS2, TF2, HL2:DM, DoD:S, GMod, L4D, L4D2, Insurgency,
  Synergy, ZPS, …) via Valve A2S (INFO, PLAYER, RULES) with challenge reuse and split
  packets; Source TCP RCON with multi-packet answers (also CS2).
- **Half-Life 1 / GoldSrc** (CS 1.6, Condition Zero, DoD, TFC, NS, TS, …): old `m` info
  format, GoldSrc split packets, UDP RCON (`challenge rcon`), `kick #userid`,
  `logaddress_add <ip> <port>`, GoldSrc `status`; "HL - …" game names and HL1 icons. RCON
  falls back to UDP automatically when the TCP RCON port is closed.
- **GameSpy 2** (e.g. Deer Hunter 2005): entered as `ip:gameport:queryport`; server info,
  players and rules (no RCON); Connect starts the game set in My Games.
- Game icons for all HLSW games (including Counter-Strike 2 and Deer Hunter 2005) and an own
  icon for GameSpy 2 servers (globe with a "2").

### Refresh and server state
- Auto refresh every **1 s** by default (Settings → Misc or the toolbar; minimum 0.4 s),
  F5 / F6 for manual refresh.
- Per-server query budget (2.5 queries/s, Settings → Misc) that respects srcds'
  `sv_max_queries_sec`; the interval cannot go below 1 / query limit; a lower limit the
  server announces in its rules (`sv_max_queries_sec` / HLDS `max_queries_sec` and window)
  is respected too; the A2S challenge is reused; the server info (ping) always comes first,
  rules are refreshed every 10 s, players of the selected server after that; the selected
  server has priority; after a timeout that server's query rate is halved and
  recovers slowly.
- A server that has not answered for **10 seconds** (at start or when it goes down) is
  offline: the whole line turns red and a notification sound plays.
- The last known name, map, game, players and other infos of every server are saved, so
  offline servers still show which server they were after a restart.

### Server list
- Several server lists; add servers in the "IP/Port" box as `IP:port`, host name, `[IPv6]:port`,
  `steam://connect/…` or `ip:port:queryport`, or many at once with Multi Server Insert;
  import / export lists as JSON.
- Game box next to "IP/Port" (Half-Life 2, Counter-Strike 2, Half-Life, GameSpy 2, with
  icons): type for new servers; shows the type of the selected server.
- Columns: country flag + # (yellow star = RCON password stored), Addr, Name with game icon,
  Game, Map, Players (humans, bots, max), Ping (current + average), Version, Location
  (provider), AddOn, Anti Cheat Tool, Ranking, Limits, Comment (editable by double-click).
- Server and player locations (country flag, city, provider) from ip-api.com, cached in
  `geo_cache.json`; local addresses show "LAN"; can be turned off.
- AddOn detection from the server rules: Source (MM:S, SMod, Stripper, Mani, ES) and
  Half-Life 1 (AMXX, AMX, ATAC, PTB, Admin Mod, dproto, MM – e.g.
  "AMXX v1.8.2, ATAC v3.0.1, PTB v1.8b3, MM v1.21.1-am"); Anti Cheat Tool shows VAC plus
  HLGuard, sXe Injected and SMAC; Ranking shows HLstatsX:CE; Limits shows time / round /
  win / frag limits.
- Search field (name, map, address); keep the list order while the mouse is over it
  (option).
- Click a header to sort; double-click a header or a column separator to fit the column to
  the longest value of **all** rows (also those scrolled out of view).
- Right-click a header: show/hide columns and **Reset column width** (server and players
  lists); hidden columns and widths are remembered.
- Right-click a server like HLSW: Connect, Copy (address, name, both, steam:// link),
  Delete, Move/Copy to server list, **Change ID** (Increase +, Decrease -, Set…, Set all
  server IDs to current sequence), Reset Average Ping, Properties (address, comment, RCON
  password), Trace Route, Rcon Status Command.
- Connect: starts the game from My Games (`+connect`, `+password`) or `steam://connect`,
  with the join password from the toolbar; logged in the Connect Log; optional actions on
  connect (minimize, minimize without traffic, start other applications); double-click to
  connect (option).

### Server details
- Server info: title, ping graph, address, ping (current and average), location, provider,
  game (folder, AppID), players, map (and next map), limits, friendly fire, server type and
  OS, version, add-ons, anti-cheat, password, tags, Steam ID, SourceTV, last seen, last
  connected, comment.
- HLSW style **ping graph** that grows with the panel, drawn in 3D: sunken frame, glossy
  hatched gray background, one shaded bar per query with a shadow – green for normal,
  orange for raised, red for high ping – and timeouts as full-height red bars; about two
  minutes of history. Numbers in the graph: scale lines, the average (dashed line), labelled
  peaks, the current ping and the value under the mouse. The scale follows the typical ping
  (90th percentile), so a single extreme ping or timeout does not squash the other bars.
- **Players** with filter (name, Steam ID, IP) and all columns of HLSW's players list
  (right-click the header): Country, #, Name, Score, Frags, Time; from RCON `status`: ID,
  Global ID (Steam ID), Ping, Loss, Rate, Slot, Addr, Bot; from the address: Country Name,
  Provider; from the server log: Kills, Deaths, Team, Statistics (Frags, Death,
  Efficiency), Teamkills, Suicides, Damage (HP, Armor) and Health (HP, Armor) – counted
  since the map started. Columns without data source (Skill, Global ID Database, Honor,
  QPort, Model, Extra) are listed greyed out like in HLSW. Right-click a player: Copy (Name, Steam ID, Addr,
  Whole Table), Rcon Status Command, Kick, Kick & Connect, Ban ID, Ban ID Kick, Ban IP,
  Ban IP Kick (permanent, 5 min, 30 min, 1 h, 1 day, 1 week).
- **Rules / cvars** with filter. Right-click: Copy (Key, Value, Both, All Rules, All Keys),
  Change Value… (sets the cvar via RCON).

### RCON
- **Rcon Config**: password per server (Hide, Save), Test, Disconnect, status, Properties;
  Receive Server Log (Get Log Internet / LAN via `logaddress_add` + `log on`, retrieve the
  log again on map change; public IP looked up automatically); **Auto Update Status**
  (periodic `status` for player details and automatic log forwarding).
- **Console** like HLSW: one selectable text area (scroll, mouse selection, Ctrl+A,
  Ctrl+C, right-click), time stamps, coloured commands and answers, switches C (translate
  log), * (hide RCON password), F (hide answers), D (date), E (empty lines), A (hide
  automatic commands), S (auto scroll), X (clear); command history (Up/Down and drop-down),
  Tab completion / Complete; cache size setting; logs can be saved to disk.
- **Chat** from the server log (team chat marked), say from openHLSW.
- **Ban List** (`listid` / `listip`): ban by Steam ID or IP with duration, unban.
- **Change Level**: map list from `maps *`, `listmaps` and the game's stock maps (maps inside
  VPK files are not reported by `maps *`), Update, Change Level, kick all players on map
  change (option).

### Window and layout
- Window size, position and the maximized state are remembered (the first start is
  maximized); the sizes of all panes (server list, info, players, rules, Rcon section) and the
  column widths of all lists are kept as well. While the window is minimized nothing is laid
  out, so minimizing no longer shrinks the panes.

### Tools
- **Trace Route window** like HLSW: per hop Ping, Ø Ping, Diff, IP, Reverse DNS, Provider
  (flag, LAN) and a ping graph, updated every second; results appear immediately; route
  changes are marked black ("Different Route"), timeouts red; Start/Stop for any address.
  Windows probes every hop with TTL limited ICMP echoes (Windows ICMP API, no admin rights);
  Linux uses `traceroute` / `tracepath` + `ping`.
- **Settings** like HLSW: My Games (all HLSW games with icons and own executables), Startup
  (selected server at start), Connecting, Rcon (cache size, save logs, auto complete, map
  change options), Connections (log port, public IP), Plugins, Sounds (per event, can be
  disabled), Misc (auto refresh, interval, query limit, list order, locations, skin, text
  size, connect on double-click).
- Settings, server lists, comments and (only when "Save" is ticked) RCON passwords are
  stored in `%APPDATA%\openHLSW\config.json` (Linux: `~/.config/openHLSW/config.json`).
- `openhlsw-cli`: query Source, GoldSrc and GameSpy 2 servers and run RCON commands from
  the command line.
- GitHub Actions build (`.github/workflows/build.yml`),
  run for every `v*` tag: Linux `.tar.gz`, `.deb`, `.rpm` and Windows `.zip`, `.msi` for
  x86, x86_64 and arm64, macOS `.dmg` and `.tar.gz` for Apple silicon (app bundle with icon,
  ad-hoc signed); a GitHub release with all packages; Linux desktop entry and icon.
- macOS: system fonts (Tahoma, Arial Unicode, PingFang, …) and Trace Route with the
  system `traceroute` / `ping`.
- `tools/fake_srcds.py` test server: Source, `--goldsrc` (HLDS), `--gamespy2 <queryport>`,
  `--latency <ms>`, rate limiting, RCON, log and chat simulation.
