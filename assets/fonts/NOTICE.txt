console.

Inc. with Reserved Font Name Liberation (https://github.com/liberationfonts). Licensed under
the SIL Open Font License 1.1 (OFL.txt). Used for "Arial" on Linux and macOS when
Microsoft's Arial is not installed (it has the same letter widths as Arial).

tahoma.ttf - the Tahoma replacement font of the Wine project (https://www.winehq.org),
from Wine 9.0, Copyright (c) Wine project authors. Licensed under the GNU Lesser General

on Linux and macOS when Microsoft's Tahoma is not installed.
