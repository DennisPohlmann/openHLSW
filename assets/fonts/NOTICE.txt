(https://www.winehq.org), taken from Wine 9.0 (wine/fonts/tahoma.sfd).

openHLSW embeds it on Linux and macOS when Microsoft's Tahoma is not installed, so the
user interface looks like the original HLSW. On Windows the system's Tahoma is used.
